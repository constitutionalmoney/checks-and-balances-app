## Open source is not brand permission

The [Apache License 2.0](./LICENSE) applies to designated repository content. It does not grant permission to use project trademarks in a way that suggests sponsorship, certification, affiliation, endorsement, official committee status, or operation by Checks and Balances Committee Ltd.

## Permitted descriptive use

Without separate written permission, a person may:

- truthfully identify the origin of unmodified software;
- state that a project is a fork of this repository;
- link to the official repository or documentation; and
- use the project name in commentary, criticism, compatibility discussion, or attribution where the use is not misleading.

A fork should use wording such as:

> Based on the open-source Checks & Balances Protocol implementation. This fork is independent and is not operated, approved, certified, or endorsed by Checks and Balances Committee Ltd.

## Permission required

Written permission is required to:

- name a service or organization in a way likely to be mistaken for the official project;
- use an official logo, seal, badge, credential design, or committee designation;
- represent a committee, deployment, credential, issuer, verifier, or API as officially recognized;
- use project marks in a domain name, app-store name, token, asset, or commercial product name; or
- imply endorsement or certification.

## Official committees and credentials

Running the software, forming a group, creating a VerusID, or issuing a technically compatible record does not by itself establish an official Checks and Balances committee or recognized credential issuer. Official recognition requires the formation, governance, legal, privacy, security, testnet, and release requirements separately approved by the project steward.

## Compatibility claims

A deployment may state that it is technically compatible only where the claim is accurate, version-specific, and does not imply recognition. Compatibility may be withdrawn from official listings where a deployment creates security, privacy, or integrity risk.

## No registration claim

This policy does not state that every listed mark is registered. Do not use a registered-trademark symbol unless the relevant registration exists and applies.
